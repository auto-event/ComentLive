🚀 BATCH MODE

ANTI-SPAM
🔒 Aturan: tiap event hanya dikomentari oleh akun pembuat event itu sendiri (dicocokkan lewat channel). Akun lain tidak dipakai.

🎯 Cara Kerja: Setiap event yang dicentang akan dikirim N komentar berturut-turut, lalu lanjut ke event berikutnya, sampai semua event selesai → bot berhenti otomatis.

Contoh: 5 event dicentang, "Komentar per event" = 2 → total 10 komentar terkirim (2 ke tiap event) → STOP.

Pesan diambil dari daftar di bawah secara rotasi global (event 1 dapat pesan A,B; event 2 dapat pesan C,D; dst).
